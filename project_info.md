# Project Information

## Title
Landing Marker Detection using Python and OpenCV

## Objective
Build a modular real-time vision prototype that detects a simple landing marker from a webcam feed using classical computer vision.

## Core Pipeline

1. Capture webcam frames.
2. Convert to grayscale.
3. Apply Gaussian blur.
4. Detect edges or threshold the image.
5. Find and filter contours.
6. Draw the best contour and bounding box.
7. Display the live result and FPS.

## Deliverables

- Modular source files
- Webcam capture
- Real-time frame processing
- Contour detection
- Bounding box visualization
- FPS display
